# PehRadar Web (`apps/web`)

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4. M1 scope: status screen that checks the API health endpoint from the browser.

## Commands (run inside `apps/web`)

| Task | Command |
|---|---|
| Install (exact versions from `package-lock.json`) | `npm ci` |
| Local config | `Copy-Item .env.example .env.local` (PowerShell) |
| Dev server | `npm run dev` → http://localhost:3000 |
| Unit tests (Vitest) | `npm test` |
| Lint / typecheck | `npm run lint` · `npm run typecheck` |
| Production build / serve | `npm run build` · `npm run start` |

`NEXT_PUBLIC_API_BASE_URL` is **inlined at build time**. Rebuild after changing it, and set it to the deployed API URL in the hosting provider before building there. No fallback URL exists: if unset, the UI shows "Not configured".

## Layout

```
src/app/            layout.tsx (fonts, metadata), page.tsx (status screen), globals.css (Design.md tokens)
src/components/     ApiStatus (+ useApiHealth hook) and tests
src/lib/config.ts   product name + API base URL
src/lib/api/        client.ts: small fetch wrapper with typed errors (network/timeout/http/invalid_response)
```

`AGENTS.md` / `CLAUDE.md` are generated by Next.js (agent hint to read bundled docs) and re-created by `next dev`.
